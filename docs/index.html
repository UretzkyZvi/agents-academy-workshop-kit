Examples first

What could an assistant actually do?

It should not “run your business.” Start with a draft, checklist, summary, or flag that a human reviews.

Intake helper

Before: New requests arrive. Someone reads them and figures out what is missing.

Assistant helps: summarize the request, list missing info, draft a reply.

Human still does: approve and send.

Follow-up helper

Before: Leads or clients go stale because nobody checks every open item.

Assistant helps: flag stale items and draft follow-ups.

Human still does: decide priority and approve messages.

Meeting cleanup helper

Before: Notes are messy and action items get lost.

Assistant helps: summarize decisions, action items, and a follow-up note.

Human still does: check accuracy.

Safe testing

Before connecting tools, test with five examples.

Most people get stuck when they start with Gmail, Calendar, CRM, OAuth, permissions, and APIs. Do this instead.

1Generate fake examplesUse made-up data based on the selected use case.
2Paste fake examples under the promptNo upload or account connection needed.
3Ask for a draft/checkNo sending. No updating.
4Try sanitized real examplesRemove private details before testing.
5Then consider read-only accessOnly if the fake and manual tests are useful.

Fake examples

The examples should match the task.

Follow-up helpers need fake open leads. Intake helpers need fake requests. Document helpers need fake document rows. Meeting helpers need fake notes. Research helpers need fake targets. The generator changes the data based on the task so the test feels real without using private information.

Why fake data first?

It lets people learn the workflow without risking private emails, client files, CRM records, or calendar data.

What does “attach” mean?

For the first test, it just means paste the fake examples below the starter prompt in the same chat. No upload is needed.

When to use real data?

Only after the fake-data test makes sense. Start with copied examples where names, emails, amounts, and sensitive details are removed.
