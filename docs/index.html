Examples first

What could an assistant actually do?

It should not “run your business.” Start with a draft, checklist, summary, or flag that a human reviews.

Intake helper

Before: New requests arrive. Someone reads them and figures out what is missing.

Assistant helps: summarize the request, list missing info, draft a reply.

Human still does: approve and send.

Follow-up helper

Before: Leads or clients go stale because nobody checks every open item.

Assistant helps: flag stale items and draft follow-ups.

Human still does: decide priority and approve messages.

Meeting cleanup helper

Before: Notes are messy and action items get lost.

Assistant helps: summarize decisions, action items, and a follow-up note.

Human still does: check accuracy.

Safe testing

Before connecting tools, test with five examples.

Most people get stuck when they start with Gmail, Calendar, CRM, OAuth, permissions, and APIs. Do this instead.

1Copy/export 5 examplesNo private account connection needed.
2Put them in a simple tableDate, person, title, notes, status.
3Ask for a draft/checkNo sending. No updating.
4Human reviews everythingKeep control with the person who owns the work.
5Then consider read-only accessOnly if the manual test is useful.
