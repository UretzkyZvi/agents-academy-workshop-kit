# Agent Patterns

## 1. Draft-only agent

The agent drafts. A human sends or finalizes.

Good for legal, insurance, healthcare, finance, and any trust-heavy workflow.

## 2. Research brief agent

The agent gathers sources and produces a decision brief.

Best when the output helps a human decide, not when the agent decides alone.

## 3. Checklist agent

The agent turns messy input into a checklist of missing items, next steps, and blockers.

This is often safer and more useful than long prose.

## 4. Review agent

The agent checks work against a rubric or policy.

Use it to improve consistency, not as the final authority.

## 5. Scheduled operator agent

The agent runs on a schedule and reports to a human channel.

Examples: daily lead scan, weekly competitor brief, monthly SOP review.
